# Spaced repetition

Distributed reviews of a fact produce more durable memories than massed practice. Anki, SuperMemo, and similar tools implement this on top of forgetting-curve estimates.

- [fact] Ebbinghaus (1885) documented the forgetting curve ^[example:setup]
- [fact] Modern algorithms use exponential backoff between reviews ^[example:setup]
- [hypothesis] Combining spaced repetition with an LLM-curated graph (this vault) might be the highest-leverage personal-learning stack [as-of 2026-01] ^[example:setup]
